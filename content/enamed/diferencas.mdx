Quatro exames aparecem frequentemente na mesma conversa em Medicina — **ENAMED, Revalida, ENADE e ENARE** — mas servem a propósitos diferentes e estão regidos por marcos legais distintos. Este resumo se baseia no <Citation source="INEP — Edital nº 71/2026 (ENAMED 2026)" url="https://www.in.gov.br/web/dou/-/edital-n-71-de-28-de-maio-de-2026-709280869" date="2026">documento oficial do ENAMED 2026 publicado no DOU em 29/05/2026</Citation> e no <Citation source="HU Brasil — Edital nº 02/2026 (ENARE 2026/2027)" url="https://www.gov.br/hubrasil/pt-br/ensino-e-pesquisa/exame-nacional-de-residencia-enare" date="2026">edital oficial do ENARE 2026/2027 publicado pela HU Brasil em 29/05/2026</Citation>.

<AnswerBox label="Em uma frase">

**ENAMED avalia a formação médica** (componente discente do ENADE para Medicina; obrigatório para concluintes e estudantes do quarto ano); **Revalida revalida diploma estrangeiro** (com OSCE); **ENADE avalia outras áreas** (Medicina é avaliada via ENAMED); **ENARE seleciona para residência médica** usando a própria prova do ENAMED como prova objetiva no Acesso Direto.

</AnswerBox>

## Quadro comparativo

| Exame | Para quem | Finalidade | Aplicador |
|---|---|---|---|
| **ENAMED** | Concluintes e estudantes do 4º ano de Medicina; graduados voluntários | Avaliar a formação médica · alimenta Conceito ENADE · habilita para ENARE | INEP (MEC) |
| **Revalida** | Médicos formados no exterior | Revalidar diploma para exercer no Brasil | INEP (MEC) |
| **ENADE** | Concluintes de cursos avaliados pelo SINAES (exceto Medicina, que usa o ENAMED) | Componente discente do SINAES | INEP (MEC) |
| **ENARE Acesso Direto** | Médicos formados que querem residência | Selecionar para vagas de PRM | HU Brasil (com apoio FGV) |

## ENAMED × ENADE — coexistem para Medicina

O ENAMED **não substitui o ENADE para Medicina** — ele é o **componente discente do ENADE para o curso de Medicina** no ciclo 2026. O concluinte de Medicina é inscrito no ENADE 2026 e presta o ENAMED; o resultado alimenta o Conceito ENADE do curso.

| Aspecto | ENAMED | ENADE |
|---|---|---|
| Áreas avaliadas | Específico de Medicina | Demais áreas avaliadas no ciclo |
| Base legal | Portaria MEC nº 330/2025 + Lei nº 12.871/2013 (4º ano) | Lei nº 10.861/2004 (SINAES) |
| Cálculo do conceito do curso | Proporção de Proficientes | Média ponderada de notas |
| Componente formação geral | Não tem | Tem |

Para o quadro completo, ver [ENAMED × ENADE — comparativo](/comparativos/enamed-vs-enade).

## ENAMED × Revalida

| Aspecto | ENAMED | Revalida |
|---|---|---|
| Público | Brasileiros formados no Brasil (concluintes e 4º ano) | Estrangeiros e brasileiros formados fora |
| Obrigatoriedade | Obrigatório (concluintes e 4º ano) | Obrigatório para exercer Medicina no Brasil com diploma estrangeiro |
| Tipo de prova | Só objetiva (100 questões, 4 alternativas, 5h) | Objetiva + OSCE (estações práticas) |
| Quem aplica | INEP | INEP |
| Decisão | Pontuação TRI + Nível Proficiente/Não Proficiente | Aprova/reprova revalidação |

Se você é estudante brasileiro de Medicina formado no Brasil, o **Revalida não se aplica a você**. Se você é médico formado no exterior querendo exercer no Brasil, o **ENAMED não se aplica a você**.

Para aprofundamento, ver [ENAMED × Revalida — comparativo completo](/comparativos/enamed-vs-revalida).

## ENAMED × ENARE — articulação direta

Este é o ponto mais relevante de 2026/2027: **a prova objetiva do ENARE Acesso Direto é literalmente a prova do ENAMED** (item 4.1.1 do Edital ENARE).

| Aspecto | ENAMED | ENARE |
|---|---|---|
| Decisão | Avalia formação + habilita para ENARE (Proficiente) | Seleciona para vaga de residência |
| Obrigatoriedade | Obrigatório para concluintes e 4º ano | Voluntário |
| Organizado por | INEP | HU Brasil (com apoio FGV) |
| Prova objetiva | Sua própria prova | **A prova do ENAMED** |
| Critério de habilitação | — | Atingir Nível Proficiente no ENAMED |
| Conversão de escala | Escala de proficiência TRI | Escala 0–1000 + bonificação +10% PRMFC |

**Importante:** estudantes do quarto ano que prestam o ENAMED **não podem** usar o resultado no ENARE (item 1.8 do Edital ENAMED).

Mais sobre a interação, ver [ENAMED × ENARE — comparativo](/comparativos/enamed-vs-enare) e [ENAMED e residência médica](/blog/enamed-e-residencia-medica).

## O que cada exame exige da preparação

| Exame | Foco do estudo |
|---|---|
| **ENAMED** | Generalismo: seis áreas com pesos referenciais (Clínica Médica, Cirurgia, Pediatria, GO, Saúde Coletiva, Ética), raciocínio clínico aplicado ao SUS, conforme Matriz de Referência (Portaria Inep nº 478/2025) |
| **Revalida** | Generalismo + habilidades práticas (OSCE) |
| **ENADE (outras áreas)** | Não se aplica a Medicina |
| **ENARE Acesso Direto** | A própria prova do ENAMED — preparação igual |

Se você é estudante brasileiro de Medicina:

1. **Faz ENAMED** se for concluinte ou estiver no quarto ano (obrigatório)
2. **Pode usar a nota do ENAMED no ENARE** se for concluinte/graduado e atingir Nível Proficiente
3. **Não faz Revalida** — só se aplica a formados no exterior
4. **Não faz ENADE separado para Medicina** — o ENAMED é o componente discente do ENADE para Medicina

## Por que tantas siglas

A multiplicação de exames reflete o desenho do sistema de avaliação superior brasileiro:

- **SINAES** (Lei 10.861/2004) — sistema geral de avaliação do ensino superior
- **ENADE** — componente discente do SINAES, com prova específica para cada área
- **ENAMED** — prova específica do ENADE para Medicina, ampliada para incluir estudantes do quarto ano por força da Lei do Mais Médicos
- **Revalida** — instrumento de equivalência para diplomas obtidos no exterior
- **ENARE** — processo seletivo de residência que adota a prova do ENAMED como sua prova objetiva no Acesso Direto

Não há sobreposição estrutural — há **articulação**. Para mais sobre a história desse desenho, ver [História do ENAMED](/enamed/historia).
