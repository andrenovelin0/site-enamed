O **ENAMED substituiu o ENADE para o curso de Medicina** a partir de 2024. Não é uma simples mudança de nome — é uma reestruturação que respondeu a três deficiências do ENADE no contexto médico: cadência trienal demais para saúde, instrumento genérico demais para a área, e ausência de nota individual.

A comparação destrincha o que mudou e o que permaneceu.

## Tabela comparativa

| Dimensão | ENAMED | ENADE |
|---|---|---|
| **Áreas avaliadas** | Específico para Medicina | Genérico — todos os cursos superiores |
| **Cadência** | Anual | Trienal |
| **Granularidade** | 6 áreas clínicas detalhadas | Componente geral + componente específico |
| **Nota individual** | Sim — TRI + banda no Lattes | Não — apenas dado agregado por IES |
| **Aplicador** | INEP | INEP |
| **Componente do CPC** | Sim (substituiu o ENADE para Medicina) | Sim (continua para outros cursos) |
| **Sistema de avaliação** | TRI + Angoff calibrados para Medicina | TRI + critério clássico |
| **Duração** | ~5h30 | ~4h |
| **Início para Medicina** | 2024 | 2004-2023 (último ciclo) |

## O que mudou — análise

### Cadência: trienal → anual

Sob ENADE, Medicina era avaliada **a cada 3 anos**. Em educação médica, três anos é uma eternidade — um currículo pode mudar três vezes antes da próxima avaliação. O ENAMED corrige isso com **cadência anual**.

Impacto: IES têm dado anual para gestão. Estudantes não esperam três anos por feedback institucional. Reformas curriculares têm efeito mensurável mais rápido.

### Especificidade: genérico → específico

ENADE usava **componente geral comum a todos os cursos** (raciocínio crítico, cidadania) + **componente específico por área**. O componente geral consumia tempo de prova sem contribuir para avaliação clínica.

ENAMED é **100% específico**: todas as ~110 questões são sobre Medicina. Sem componente geral. Maior densidade de informação útil.

### Nota individual: ausente → presente

ENADE não gerava nota individual visível ao estudante — apenas dado agregado por IES. O candidato sabia se sua turma tinha ido bem; não sabia seu próprio nível.

ENAMED gera **nota TRI individual + banda** que entra automaticamente no Lattes. Diferença qualitativa para o estudante: você tem uma medida pessoal de competência.

### Calibração: ajustada para Medicina

ENAMED usa **TRI + Angoff** especificamente calibrados para o conteúdo médico. ENADE também usava TRI, mas com calibração mais genérica.

Impacto: maior discriminação entre candidatos de diferentes níveis. Menos ruído estatístico.

## O que permaneceu

### Aplicador

Continua sendo o **INEP**, com mesma estrutura operacional (locais de aplicação, logística, recursos administrativos).

### Função regulatória

O ENAMED **alimenta o CPC** da mesma forma que o ENADE alimentava. O peso é até maior na composição. Sistema regulatório do MEC (TSD, redução de vagas, sanções) continua.

### Estrutura de itens

Ambos usam **múltipla escolha em caso clínico**. Não há OSCE no ENAMED (diferente do Revalida). Manteve-se o formato testado de avaliação por questões objetivas contextualizadas.

### Obrigatoriedade

Tanto ENADE quanto ENAMED são **obrigatórios** para concluintes. Ausência sem justificativa pode bloquear colação de grau.

## Por que substituir?

A decisão de criar avaliação dedicada respondeu a três pressões:

1. **Granularidade insuficiente** — ENADE não dava sinal fino sobre competência clínica
2. **Cadência trienal demais** — três anos de atraso entre uma avaliação e outra é muito para cursos de saúde
3. **Demanda da CNRM e Sociedades médicas** por avaliação dedicada à formação médica

A Portaria MEC nº 2.435/2024 formalizou a substituição.

## Outros cursos continuam no ENADE

A mudança foi **específica para Medicina**. Outros cursos da saúde (Enfermagem, Odontologia, Farmácia, etc.) continuam avaliados pelo ENADE no ciclo trienal padrão.

Há discussão pública sobre **expansão do modelo ENAMED** para outras áreas críticas (Direito, Engenharia, Educação), mas não há decisão regulatória até maio/2026.

## Para coordenadores

Implicações práticas:

- **Não é mais possível esperar 3 anos** pra ver resultado de mudança curricular
- **Indicador de gestão se tornou anual** — pressão maior, mas também feedback mais rápido
- **Nota individual no Lattes** muda comportamento de estudantes (mais engajados)
- **CPC sente o impacto** com maior frequência

## Para estudantes

Implicações:

- **A prova é mais focada** — só conteúdo médico, sem componente geral
- **Sua nota é pessoal** — fica no Lattes para sempre
- **Comparação anual com pares nacionais** — você sabe sua posição relativa
- **Mais cobrança institucional** — IES priorizam preparação dos alunos
