# Story 003.1 — MDX pipeline + `/enamed` como pilar piloto

**Epic:** EPIC-003 — Camada de conteúdo MDX
**Status:** Ready for Review (consolidada por @dev em 2026-05-27 a pedido do owner)
**Created:** 2026-05-27 (modo compacto — implementação + drafting na mesma rodada)

## User Story

**Como** time editorial do ENAMED,
**eu quero** uma pipeline MDX local funcionando em pelo menos um pilar (`/enamed`),
**para que** eu possa escrever/editar conteúdo em arquivos `.mdx` versionados e ver o resultado renderizado no site com a identidade visual aplicada.

## Acceptance Criteria

1. **AC1** — `@next/mdx` + `@mdx-js/loader` + `@mdx-js/react` + `@types/mdx` + `remark-frontmatter` + `remark-mdx-frontmatter` + `remark-gfm` instalados.
2. **AC2** — `next.config.ts` configurado com `pageExtensions` incluindo `mdx`/`md` e plugin `createMDX` aplicado.
3. **AC3** — `src/mdx-components.tsx` mapeia todas as tags HTML padrão (h1–h6, p, ul, ol, li, blockquote, code, pre, table, a, img, hr, strong, em) para estilos do design system (Poppins display em headings, Raleway body, cores neutral/brand).
4. **AC4** — Componentes MDX customizados disponíveis: `<Callout>` (variantes `info`/`warn`/`success`), `<CompareTable>` (placeholder simples), `<CTA>` (wrap do `<Button>`).
5. **AC5** — `content/pilares/enamed.mdx` criado com conteúdo-semente em pt-BR cobrindo: definição, objetivos, elegibilidade, contexto histórico, diferenciação Enamed×Revalida×residência, FAQ inline. Conteúdo segue voz da marca (amigável + moderno + ousado, sem infantilizar).
6. **AC6** — `src/app/enamed/page.tsx` refatorado: importa o MDX, renderiza dentro de um template (PageHero + conteúdo + CTA cruzado), aplica metadata (title, description, canonical).
7. **AC7** — Frontmatter do MDX exportado como `metadata` (title, description, eyebrow, updatedAt) e consumido na page.
8. **AC8** — Schema.org Article injetado na page (script JSON-LD via componente já existente em `src/components/structured-data.tsx` — estender se preciso).
9. **AC9** — Build (`npm run build`) gera `/enamed` como página estática. Lint limpo.
10. **AC10** — Browser: `/enamed` renderiza o conteúdo MDX com hierarquia tipográfica visível, sem console errors. Screenshot anexado.
